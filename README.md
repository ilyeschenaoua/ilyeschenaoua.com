# ilyeschenaoua.com

Personal website of Ilyes Saad Chenaoua: career, portfolio and a bit of life off the clock.

Live at **https://ilyeschenaoua.com**

## What's inside

- `index.html` – the whole site: Home, Career, Personal and Portfolio views
- `styles.css` – layout, theme (light and dark) and animations
- `script.js` – page transitions, splash screen, lightbox and small interactions
- `career/`, `personal/`, `portfolio/` – images and logos for each page

Plain HTML, CSS and JavaScript. No build step: open `index.html` in a browser to run it locally.

Hosted on Netlify.
